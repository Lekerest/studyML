# Lab 13 — REST API and React
28_04_2026

## Цель работы
Исследовать взаимодействие клиентской и серверной части приложения на основе **HTTP**, **REST**, **FastAPI**, **React** и **CORS**.

В рамках работы было выполнено:
- создание REST API на FastAPI,
- настройка CORS для подключения фронтенда,
- обучение модели машинного обучения на датасете **Wine**,
- создание маршрутов API для получения информации о модели,
- получение метрик качества модели через GET-запрос,
- получение примеров объектов через GET-запрос,
- выполнение предсказания через POST-запрос,
- создание React-клиента,
- отправка JSON-запросов из React через Fetch API,
- вывод результата предсказания и вероятностей классов на странице.

---

## Используемые технологии

- **HTTP** — протокол обмена данными между клиентом и сервером  
- **REST** — архитектурный стиль для построения API  
- **FastAPI** — создание серверного API  
- **Pydantic** — описание и проверка входных JSON-данных  
- **CORSMiddleware** — разрешение запросов от React-клиента  
- **React** — создание клиентского интерфейса  
- **Fetch API** — отправка HTTP-запросов из браузера  
- **scikit-learn** — обучение модели машинного обучения  
- **Wine dataset** — встроенный датасет sklearn

# Эксперименты

## 🔹 Exp1 — Создание REST API на FastAPI

На первом этапе было создано FastAPI-приложение с набором REST-маршрутов.

Были реализованы маршруты:

- GET /
- GET /api/health
- GET /api/model/info
- GET /api/model/metrics
- GET /api/examples
- POST /api/predict

**Результат:**
- API запускается локально
- Документация доступна через Swagger
- Сервер возвращает данные в формате JSON

**Вывод:**  
FastAPI позволяет быстро создать REST API с понятными маршрутами и автоматической документацией.

---

## 🔹 Exp2 — Обучение ML-модели

На втором этапе была обучена модель **LogisticRegression** на датасете **Wine**.

Перед обучением признаки были масштабированы с помощью **StandardScaler**. Для обучения и оценки качества использовалось разделение на обучающую и тестовую выборки.

**Результат:**
- Shape X: (178, 13)
- Shape y: (178,)
- Shape X_train: (142, 13)
- Shape X_test: (36, 13)
- Accuracy: 0.9722

**Вывод:**  
Модель показала высокое качество классификации. Accuracy на тестовой выборке составила 0.9722.

---

## 🔹 Exp3 — JSON-запросы и Pydantic

На третьем этапе была создана Pydantic-модель **WineRequest**, которая описывает 13 признаков объекта Wine.

React-клиент отправляет эти признаки в формате JSON на маршрут:

- POST /api/predict

**Результат:**
- Входные данные проверяются автоматически
- При ошибочном формате данных FastAPI возвращает 422
- API возвращает predicted_class_id, predicted_class_name и probabilities

**Вывод:**  
Pydantic упрощает валидацию JSON-запросов и делает API более надежным.

---

## 🔹 Exp4 — Настройка CORS

На четвертом этапе была настроена политика **CORS** для взаимодействия React и FastAPI.

Были разрешены адреса:

- http://localhost:3000
- http://127.0.0.1:3000
- http://localhost:5173
- http://127.0.0.1:5173

**Результат:**
- React-клиент может отправлять запросы к FastAPI
- Браузер не блокирует запросы между разными портами
- API поддерживает GET и POST-запросы с фронтенда

**Вывод:**  
CORS необходим при разделении фронтенда и бэкенда на разные локальные адреса.

---

## 🔹 Exp5 — React-клиент

На пятом этапе был создан React-клиент для работы с REST API.

Клиент выполняет:
- загрузку информации о модели,
- загрузку метрик качества,
- загрузку примеров объектов,
- заполнение формы признаков,
- отправку POST-запроса на предсказание,
- отображение класса и вероятностей.

**Результат:**
- Страница показывает модель, датасет, accuracy и количество классов
- Можно выбрать готовый пример объекта
- После запроса отображаются вероятности классов
- Матрица ошибок отображается на странице

**Вывод:**  
React удобно использовать как клиентскую часть для REST API, так как состояние интерфейса можно обновлять после каждого HTTP-запроса.

# Запуск проекта

Установка зависимостей backend:

```bash
pip install -r requirements.txt
```

Запуск FastAPI:

```bash
fastapi dev main.py
```

Swagger-документация:

```text
http://127.0.0.1:8000/docs
```

Установка зависимостей frontend:

```bash
cd frontend
npm install
```

Запуск React:

```bash
npm run dev
```

React-клиент:

```text
http://127.0.0.1:3000
```
