## Используемые обозначения

- **sigmoid** — сигмоидная функция активации  
- **min** — слой выбора минимального значения  
- **max** — слой выбора максимального значения  
- **y** — выход сети  
- **E** — ошибка модели

# Выполненное задание

## 🔹 Exp1 — Forward pass

На первом этапе было записано прямое распространение сигнала через сеть.

Входные значения проходят через сигмоидную функцию:

- i1 = sigmoid(x1)
- i2 = sigmoid(x2)

После этого значения проходят через слои min и max:

- omin = min(i1, i2)
- omax = max(i1, i2)

Затем результаты складываются:

- y = omin + omax

**Вывод:**  
Прямое распространение показывает, как входные значения преобразуются в итоговый выход сети.

---

## 🔹 Exp2 — Simplification

На втором этапе было выполнено упрощение выражения для выхода сети.

Так как сумма минимального и максимального значения двух чисел равна сумме этих чисел:

- min(i1, i2) + max(i1, i2) = i1 + i2

то выход сети можно записать проще:

- y = sigmoid(x1) + sigmoid(x2)

**Вывод:**  
Упрощение позволило свести сеть к сумме двух сигмоидных функций.

---

## 🔹 Exp3 — Backward pass

На третьем этапе было выполнено обратное распространение ошибки.

Для нахождения производных использовалось правило цепочки:

- dE/dx1 = dE/dy * dy/dx1
- dE/dx2 = dE/dy * dy/dx2

Также была использована производная сигмоидной функции:

- sigmoid'(x) = sigmoid(x)(1 - sigmoid(x))

**Результат:**

- dE/dx1 = dE/dy * sigmoid(x1)(1 - sigmoid(x1))
- dE/dx2 = dE/dy * sigmoid(x2)(1 - sigmoid(x2))

**Вывод:**  
Производные ошибки по входам выражаются через ошибку на выходе сети и производную сигмоидной функции.
