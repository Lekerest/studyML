# Lab 6 — Metric Classification with KNN
10_03_2026

## Цель работы
Исследовать работу метрического метода классификации **k-ближайших соседей (k-NN)** на датасете **Wine**, подобрать оптимальное значение параметра `k` и оценить качество модели.

В рамках работы была выполнена:
- загрузка датасета **Wine**,
- масштабирование признаков с помощью **StandardScaler**,
- реализация собственного класса **KNN**,
- подбор оптимального `k` с использованием **5-Fold Cross Validation**,
- построение графика зависимости **accuracy** от числа соседей,
- финальная проверка модели на тестовой выборке.

---

## Используемые метрики

- **Accuracy** — доля правильно классифицированных объектов  
- **Cross Validation Accuracy** — средняя точность по нескольким разбиениям выборки  
- **Test Accuracy** — точность на отложенной тестовой выборке  

---

# Эксперименты

## 🔹 Exp1 — KNN, k = 1

Проверена работа алгоритма при минимальном числе соседей.  
Модель показала высокую точность, но оказалась более чувствительной к отдельным объектам и шуму.

**Результат:**
- Mean CV Accuracy: 0.9440  

**Вывод:**  
При `k = 1` модель работает хорошо, но слишком сильно зависит от ближайшей точки.

---

## 🔹 Exp2 — KNN, подбор `k` от 1 до 15

Для каждого значения `k` была выполнена **5-fold cross-validation**, после чего вычислена средняя точность.  
Это позволило определить значение `k`, при котором классификация становится наиболее стабильной и точной.

**Результаты:**
- `k = 3` → Mean CV Accuracy: 0.9551  
- `k = 6` → Mean CV Accuracy: 0.9552  
- `k = 9` → Mean CV Accuracy: 0.9608  
- `k = 11` → Mean CV Accuracy: 0.9610  
- `k = 15` → Mean CV Accuracy: 0.9721  

**Вывод:**  
Наилучшее среднее качество было получено при `k = 15`.

---

## 🔹 Exp3 — Финальная модель KNN с лучшим `k`

После подбора параметра была обучена финальная модель с оптимальным числом соседей.  
Проверка на тестовой выборке показала максимально высокий результат.

**Результат:**
- Best k: 15  
- Mean CV Accuracy: 0.9721  
- Test Accuracy: 1.0000  

**Вывод:**  
Модель с `k = 15` классифицировала все объекты тестовой выборки правильно.

# Общий вывод

1. Метод **k-ближайших соседей** показал высокое качество на датасете **Wine**.
2. Масштабирование признаков оказалось важным этапом подготовки данных, поскольку k-NN чувствителен к масштабу признаков.
3. Подбор числа соседей действительно влияет на качество классификации: лучшие результаты были получены при больших значениях `k`.
4. Оптимальным значением в данном эксперименте стало **k = 15**, при котором средняя точность по кросс-валидации составила **0.9721**.
5. Финальная модель с `k = 15` показала **1.0000** accuracy на тестовой выборке, что говорит о хорошей разделимости классов в датасете Wine и высокой эффективности k-NN для данной задачи.
