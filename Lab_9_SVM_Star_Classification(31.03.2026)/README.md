# Lab 9 — SVM Star Classification
31_03_2026

## Цель работы
Исследовать метод опорных векторов (**SVM**) на датасете **Star Classification** и подобрать лучшие параметры модели для классификации астрономических объектов.

В рамках работы была выполнена:
- загрузка и анализ данных,
- проверка пропущенных значений и дубликатов,
- удаление ID-признаков,
- обработка выбросов,
- кодирование целевой переменной,
- формирование стратифицированной подвыборки,
- обучение модели **SVM** с RBF-ядром,
- подбор параметров **C** и **gamma** через **GridSearchCV**,
- оценка качества по метрикам **Accuracy**, **Precision**, **Recall** и **F1-score**,
- визуализация результатов в виде тепловой карты.

---

## Используемые метрики

- **Accuracy** — доля правильно классифицированных объектов  
- **Precision** — точность предсказания класса  
- **Recall** — полнота распознавания класса  
- **F1-score** — гармоническое среднее между precision и recall

# Эксперименты

## 🔹 Exp1 — SVM with weak regularization

В первом эксперименте рассматривались модели с малым значением параметра **C**.

Параметр **C** отвечает за штраф за ошибки классификации. При маленьком значении C модель допускает больше ошибок и строит более мягкую границу между классами.

**Результат:**
- C = 0.1
- gamma = 0.001
- Mean CV Accuracy: 0.5946  

**Вывод:**  
Модель показала слабый результат. Малое значение C вместе с маленьким gamma сделало границу слишком простой, поэтому модель недообучилась и плохо разделила классы.

---

## 🔹 Exp2 — SVM with medium parameters

Во втором эксперименте рассматривались средние значения параметров **C** и **gamma**.

Параметр **gamma** определяет влияние отдельных объектов на форму разделяющей границы. При увеличении gamma модель начинает сильнее учитывать ближайшие объекты.

**Результат:**
- C = 1
- gamma = 0.1
- Mean CV Accuracy: 0.9254  

**Вывод:**  
Качество модели заметно улучшилось. Граница стала более гибкой, поэтому SVM начал лучше разделять классы GALAXY, QSO и STAR.

---

## 🔹 Exp3 — SVM with strong regularization

В третьем эксперименте рассматривались большие значения параметра **C**.

Большое значение C сильнее штрафует модель за ошибки классификации. Это помогает точнее разделить классы, если данные хорошо отделимы в признаковом пространстве.

**Результат:**
- C = 10
- gamma = 0.1
- Mean CV Accuracy: 0.9542  

**Вывод:**  
Модель показала высокий результат. Увеличение C позволило лучше подстроить разделяющую границу под данные, но при слишком больших значениях gamma качество начинало снижаться.

---

## 🔹 Exp4 — Best SVM model

В четвертом эксперименте была выбрана лучшая модель по результатам **GridSearchCV**.

Лучшие параметры:
- C = 100
- gamma = 0.01

**Результат:**
- Mean CV Accuracy: 0.9579  
- Test Accuracy: 0.9700  

**Classification report:**
- GALAXY: precision = 0.98, recall = 0.97, f1-score = 0.97  
- QSO: precision = 0.98, recall = 0.93, f1-score = 0.95  
- STAR: precision = 0.94, recall = 1.00, f1-score = 0.97  

**Вывод:**  
Лучшая модель показала высокое качество классификации. На тестовой выборке accuracy составила 0.9700. Лучше всего модель распознала класс STAR, а основные ошибки возникли между классами GALAXY и QSO.
