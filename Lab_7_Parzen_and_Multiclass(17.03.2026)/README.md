# Эксперименты

## 🔹 Exp1 — Parzen Window

Для метода Парзеновского окна был выполнен подбор параметра `h` на тестовой выборке.  
Лучший результат был получен при среднем значении ширины окна.

**Результаты:**
- `h = 0.1` → Accuracy: 0.9181  
- `h = 0.3` → Accuracy: 0.9298  
- `h = 0.5` → Accuracy: 0.9181  
- `h = 0.7` → Accuracy: 0.9357  
- `h = 1.0` → Accuracy: 0.9298  
- `h = 1.5` → Accuracy: 0.8538  
- `h = 2.0` → Accuracy: 0.7895  

**Вывод:**  
Наилучшее качество для метода Парзеновского окна достигнуто при `h = 0.7`. Слишком маленькие значения делают модель чувствительной к локальному шуму, а слишком большие приводят к чрезмерному сглаживанию.

**Вывод:**  
Лучший результат метода потенциальных функций также был достигнут при `h = 0.7`. Однако по accuracy он уступил Парзеновскому окну, а рост числа потенциалов при больших `h` не привёл к улучшению качества.
